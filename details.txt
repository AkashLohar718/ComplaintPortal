# 📌 Complaint Management System — Detailed Project Information

## 1. Project Overview

### Project Name

**Complaint Management System**

### Project Type

Web-based complaint registration, tracking, and management system.

### Main Purpose

The purpose of the system is to provide a centralized platform where:

**Users**

* Register/login
* Submit complaints
* Track submitted complaints
* View complaint details
* Check complaint status
* See remarks from the administrator

**Admins**

* View all complaints
* Search and filter complaints
* Change complaint status
* Add remarks
* Monitor overall complaint statistics

The basic workflow is:

```text
User
  ↓
Register / Login
  ↓
Submit Complaint
  ↓
Complaint Stored in Database
  ↓
Admin Reviews Complaint
  ↓
Admin Updates Status
  ↓
Admin Adds Remarks
  ↓
User Tracks Complaint
```
